# Fem 60 anys

**Estem d'aniversari!** L'Agrupament Escolta i Guia Jaume Caresmar i Maria Antònia Salvà ha realitzat dutant aquests curs 2012/2013 el seu 60è aniversari (1952/53-2012/13).

Durant els darrers mesos hem realitzat diverses activitats (Presentació documental 'Els inicis de l'escoltisme a Igualada', projecte 60 anys-60 cims, Ciri Votiu, Missa del Gall, Exposició del 60è aniversari, Festa de Sant Jordi-60 anys i la pujada a un pic tots junts).
