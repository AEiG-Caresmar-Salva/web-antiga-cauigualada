# Sortida a l'Anella Verda

El diumenge 23 d'octubre vam fer una sortida matinal per descobrir l'Anella Verda d'Igualada! Vam aprendre què significa l'Anella Verda i també molts jocs per anar-nos coneixent entre nosaltres!
